# Features v2 Roadmap (branch `features-v2`)

Goal: add patches, MIDI extras, filter envelope + velocity toggle + key tracking, LFO + glide, unison, more effect dials, QWERTY keyboard, WAV recording, MIDI clock with tempo-synced delay, packaging/CI. NOT in scope: arpeggiator/sequencer, a packaged .exe, a LICENSE file (owner's decisions).

## Rules for every task
- One commit per task on `features-v2`; trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Repo root, Git Bash, `.venv/Scripts/python.exe -m pytest -q`.
- TDD: tests first, see red, implement, full suite green.
- **Default sound must not change.** Every new feature defaults to off/neutral; `tests/test_golden_sound.py` (Task 0) must keep passing unchanged. If a task legitimately has to change it, stop and report instead.
- Every new user-controllable value is a registry `Param` (`midi_synth/params.py`) so it automatically gets a GUI control, MIDI learn, patch support and console access where applicable. Engine setters take `self.lock` and clamp.
- Update `README.md` for each feature. Add console commands where listed. Don't touch `tests/reference_dsp.py` existing classes.
- Performance: run `.venv/Scripts/python.exe bench.py`; the "all four effects" case must stay under 50% of budget. Never block or raise on the audio thread.
- GUI: follow existing patterns (`ParamControl`, `GROUP_POSITIONS`, `Param.under`, `ValueSlider`, `Knob`). Keep the offscreen GUI tests passing; add tests for new GUI pieces.

## Task 1 — Patches
New `midi_synth/patches.py` + GUI/console/CLI.
- `PatchError`; `capture(registry)` -> `{param_id: value}` for every registry param except `master_gain` (constant `PATCH_EXCLUDED`); `apply(registry, values, defaults)` -> list of warning strings: iterate the registry IN REGISTRY ORDER (mod_mode is registered before fm_depth so the mode's side effect on depth is overridden by the stored depth); a param missing from `values` takes `defaults[pid]` (so loading a patch always fully defines the sound and old patches get new params at default); unknown ids ignored with a warning; invalid values (ValueError/TypeError) skipped with a warning; values go through `registry.set` (clamping + listeners).
- `PatchStore(directory)` mirroring `ProfileStore` (reuse `validate_name`, atomic write via `_atomic_write_json`, case-insensitive names, corrupt files skipped with `warnings`): files `<dir>/patches/<name>.json` = `{"version": 1, "name": ..., "params": {...}}`; `names()`, `load(name)` -> dict, `save(name, values)`, `create_from(...)`, `duplicate`, `rename`, `delete`, `last_used()` / `set_last_used(name)` stored in `<dir>/patch_settings.json`. Version handling: files with `version` > current raise `PatchError("newer format")`; a `MIGRATIONS = {}` dict hook (version -> function) applied in order for older versions (empty now, tested with a fake migration). Errors/warnings go to the status bar. Applying a patch must not trigger N slow operations on the GUI thread (just the setters).
- Console: `patch list`, `patch save <name>`, `patch load <name>`, `patch delete <name>`. CLI: `--patch NAME` (loaded after the engine is built, before the GUI opens); with no flag, the last-used patch is applied at startup if it exists (warn and continue if it is unreadable).

## Task 3 — Velocity toggle, filter envelope, key tracking
- Param `velocity_on` TOGGLE "Velocity" (group "Master", default True). Engine `note_on`: voice velocity = `velocity/127` if on else `FIXED_VELOCITY = 100/127`. Also expose `set_velocity_on`.
- Filter modulation params (group "Filter"): `flt_env_amount` bipolar -1..1 ("Env Amt", `FLT_ENV_OCTAVES = 6.0` octaves at full), `flt_keytrack` 0..1 ("Key Trk": cutoff x `2**((note-60)/12*keytrack)`), `flt_vel` 0..1 ("Vel>Cut": cutoff x `2**(flt_vel * FLT_VEL_OCTAVES * (velocity-0.5))`, `FLT_VEL_OCTAVES = 6.0`). New group "Filter Env" with `flt_attack`, `flt_decay`, `flt_sustain`, `flt_release` sliders (same ranges/log scaling/formatters as the amp ones; defaults A 0.005, D 0.3, S 0.3, R 0.3). Rename the existing group "Envelope" to "Amp Envelope".
- Voice: each voice gets a second `Envelope` (`flt_env`) configured like the amp one (engine pushes shapes to all voices), triggered/released with the note. In `Voice.render`, when `lpf_mode == "voice"` and any of env amount / keytrack / `flt_vel` is non-zero: compute a per-voice cutoff `base * 2**(env_mean * amount * FLT_ENV_OCTAVES + keytrack_oct + vel_oct)` (env level = mean of `flt_env.process(n)` over the block), clamp to `[LPF_MIN_HZ, 0.45*sr]`, treat >= bypass threshold as bypass, and build coefficients with `lpf_coefficients` per voice per block; otherwise use the shared `params["lpf_coeffs"]` exactly as today (bit-identical fast path). Only advance `flt_env` when the amount is non-zero. In master-bus mode these modulations are ignored (documented).
- Tests: defaults leave `RefVoice` comparisons and the golden test unchanged; velocity off -> notes of different velocity render identically; keytrack 1 -> cutoff of note+12 is twice (assert on the coefficients/cutoff function, plus a spectral check); env amount > 0 raises spectral centroid during the attack vs amount 0 (with a low base cutoff); negative amount closes it; `flt_vel`; master mode ignores modulation; shapes reach all voices; GUI groups/controls exist; patch capture includes the new params.

## Task 4 — LFO and glide
- Params (group "LFO"): `lfo_rate` 0.05-20 Hz log (default 5), `lfo_depth` 0-1 (default 0 = off), `lfo_wave` CHOICE sine/triangle/saw/square/random, `lfo_dest` CHOICE pitch/filter/pwm/amp. Group "Glide": `glide_time` 0-2 s (default 0 = off, log-ish: use linear 0-2 or log with min 0.001 and a 0 = off special-case — choose linear), `glide_legato` TOGGLE (glide only when another note is held; default False).
- Engine: a global LFO (phase advanced per block; `random` = sample-and-hold updating once per LFO cycle, seeded). Per block compute the LFO value at block centre (scalar, -1..1) and, for amp, a per-sample array. Destination effects: pitch ± `depth * 2` semitones (multiply `pitch_ratio` per block; applied in the voice via the params dict, do not mutate the user's pitch-bend param), filter ± `depth * 3` octaves on the cutoff (voice path uses the per-voice coefficient route from Task 3 when LFO filter depth > 0; master-bus mode applies it to the shared coefficients), pwm ± `depth * 0.25` added to both PWM values then clamped to [0, 0.5], amp tremolo gain `1 - depth * (0.5 - 0.5 * lfo)` per sample.
- Glide: engine remembers the last played note frequency; `Voice.note_on(..., glide_from=None)`; the voice moves from `glide_from` to its target over `glide_time` (linear in semitones/log-frequency), evaluated per block (block-centre value). Legato mode: only glide if some voice is currently gated when the new note arrives. Time 0 = exactly today's behaviour.
- Defaults must keep the golden sound and the voice goldens bit-identical when depth = 0 and glide = 0 (skip all LFO work then).
- Tests: waveform generators (range, period, s&h holds), each destination measurably changes a rendered signal at depth 1 and leaves it identical at depth 0, glide frequency path (second note's early pitch near the first note's, converging within the glide time; legato mode glides only when overlapping), GUI controls, patch capture.
- Console: `lfo <rate> <depth>`, `glide <seconds>`.
Commit "Add LFO (pitch/filter/PWM/amp) and glide".

## Task 5 — Unison
- Params (group "Unison"): `unison_voices` CHOICE "1".."12" (default "1"), `unison_detune` 0-50 cents (default 15), `unison_spread` 0-1 stereo spread (default 0.5). With width 1 nothing changes (bit-identical).
- Engine: `note_on` allocates `N = min(width, max_voices)` voices as one group (shared group id, note, velocity). Voice i of N gets a detune of `linspace(-1, 1, N)[i] * detune` cents (0 for N = 1), a pan `linspace(-1, 1, N)[i] * spread`, gain `1/sqrt(N)` (exactly 1.0 for N = 1) and random starting oscillator phases (engine-level seeded `numpy` RNG, only when N > 1; N = 1 keeps phase 0). Voice stealing: take idle voices first; if more are needed steal WHOLE groups, preferring released groups, then oldest; each stolen voice hard-retriggers as today. `note_off` / sustain pedal / `all_notes_off` already operate by note, so they release the whole group; verify.
- Voice: add `detune_cents`, `pan`, `gain` attributes applied in `render` (frequency multiplier on both oscillators; output gain).
- Render: voices are summed into a left and right accumulator using a balance law `gl = 1 - max(0, pan)`, `gr = 1 + min(0, pan)` (centre = 1.0 both, so nothing changes for centred voices). When every active voice has pan 0, use the existing mono sum + duplicate path (bit-identical). In master-bus LPF mode with panned voices, filter L and R with two `LowPass` instances (add `master_lpf_r`; reset both on mode/bypass transitions).
- Tests: group allocation (N voices per note, polyphony 12//N), detune/pan/gain values, whole-group stealing, note_off releases the whole group, width 1 identical to the golden sound, stereo spread makes L != R and spread 0 keeps L == R, loudness with N = 12 within 3 dB of N = 1, spectral broadening with detune, master-LPF stereo path, GUI controls, bench with width 12 stays within the same budget as 12 plain voices.
- Console: `unison <1-12> [detune_cents] [spread]`.
Commit "Add unison with detune, stereo spread and group voice stealing".

## Task 7 — MIDI clock and tempo-synced delay
- `midi_synth/tempo.py`: `TempoTracker` with `on_clock(timestamp)` (24 pulses per quarter note; use `time.perf_counter()` captured by the caller), `on_start()`, `on_stop()`, `on_continue()`, smoothing over the last 48 pulses (median of intervals -> BPM, EMA, quantised to 0.1 BPM), `external_bpm()` (None when no clock for more than 1 s), `running` flag, `effective_bpm(manual_bpm)` (external if present else manual).
- Params: `tempo_bpm` 40-240 (default 120, group "Tempo"), `fx_delay_sync` TOGGLE (default False), `fx_delay_division` CHOICE `1/1, 1/2, 1/2., 1/4, 1/4., 1/4T, 1/8, 1/8., 1/8T, 1/16, 1/16.` default `1/8` with a beats table (1/4 = 1 beat ... dotted x1.5, triplet x2/3). The engine owns `self.tempo`; MidiInput forwards mido `clock/start/stop/continue` to it. In `render`, when delay sync is on compute `ms = 60000/bpm * beats`, clamp to the delay's range and only call `set_time_ms` when the value changed by more than 0.5 ms (no per-block churn). Sync off = manual time knob exactly as today.
- GUI: "Tempo" group: manual BPM control and a live label `120.0 BPM (MIDI clock)` / `(manual)` refreshed by the existing timer; the delay sync toggle + division combo live in the delay block of the Effects group.
- Tests: tracker math on synthetic timestamps (120 BPM +/- 0.3, jitter robustness, timeout fallback, start/stop), beats table, engine sync (expected ms, clamp at 4000, sync off unchanged, no churn), MidiInput forwards clock messages, GUI label, patches capture the new params, golden sound unchanged.
- Console: `tempo <bpm>`, `delaysync <on|off> [division]`.
